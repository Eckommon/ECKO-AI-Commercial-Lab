# AURORA asset manifest

All five benchmark stills were generated for this fictional campaign in ChatGPT image generation during the Factory v1.0 design session.

| File | Intended use |
|---|---|
| `shot-01-hero.png` | dark hero reveal / aurora scan |
| `shot-02-macro.png` | condensation macro / digital orbit |
| `shot-03-portrait.png` | portrait product composition |
| `shot-04-impact.png` | coffee + ice impact peak |
| `shot-05-endcard.png` | final hero / end card |

These files are benchmark source assets, not representations of a real commercial product.

> Binary source assets are intentionally not embedded in this bootstrap commit. Add the approved generated PNGs under this directory before render. The storyboard validator will fail closed if an asset is missing.
